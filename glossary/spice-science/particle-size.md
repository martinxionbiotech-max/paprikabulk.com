# Particle Size

## Definition

Particle size refers to the fineness of ground paprika powder, measured by the mesh size of the sieve through which the powder passes. It directly affects color release, dispersion, and application performance.

## Overview

Particle size is a critical specification parameter for paprika powder. Different applications require different particle sizes — from coarse grind (for dry rubs and visible flakes) to fine powder (for smooth sauces and emulsions).

## Technical Explanation

**Common Particle Size Standards:**

| Mesh Size | Opening (µm) | Application |
|-----------|-------------|-------------|
| 20 mesh | 840 | Coarse grind, dry rubs |
| 40 mesh | 420 | Standard grind, general cooking |
| 60 mesh | 250 | Fine powder, sauces |
| 80 mesh | 177 | Very fine, emulsions |
| 100 mesh | 149 | Ultrafine, oleoresin extraction |

**Measurement Methods:**
- Sieve analysis (mechanical or air-jet)
- Laser diffraction (for fine powders)
- Microscopic analysis

**Impact on Quality:**
- Finer grinding = faster color release but greater surface oxidation
- Coarser grind = better visual appearance, slower color release
- Over-grinding generates heat that degrades color

## Importance in Paprika Documentation

Specifications must clearly state the target mesh size. Different grades of paprika powder may share the same ASTA value but differ in particle size for specific applications.

## Frequently Asked Questions

**Q: Does finer particle size increase color strength?**
A: Perceived color may appear stronger due to faster release, but the total carotenoid content (ASTA) remains the same regardless of particle size.

**Q: What is the standard particle size for industrial paprika?**
A: 40–60 mesh is the most common range for bulk industrial paprika powder. Specialty applications may require different specifications.
