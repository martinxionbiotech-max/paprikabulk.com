# Batch Number

## Definition

A batch (or lot) number is a unique alphanumeric identifier assigned to a specific production batch of paprika, enabling traceability from raw material through processing to final shipment.

## Overview

Batch/lot numbers are the backbone of product traceability. Each batch of paprika receives a unique identifier that links the finished product to its raw material origin, processing parameters, and quality test results.

## Technical Explanation

**Typical Batch Number Structure:**
```
[Year][Month][Product Code][Sequence]
Example: 2607PP001
- 26 = 2026
- 07 = July
- PP = Paprika Powder
- 001 = First batch that month
```

**Traceability Chain:**
1. Raw material intake recorded (origin, harvest date, supplier)
2. Processing batch assigned (drying, grinding, blending)
3. In-process QC samples collected
4. Finished product tested (COA generated)
5. Batch number printed on labels and COA
6. Shipping documents reference batch number

## Importance in Paprika Documentation

The batch number is the critical link between the physical product and its documentation. Every COA includes the batch number, and buyers should verify that the batch number on the product label matches the COA.

## Frequently Asked Questions

**Q: How large is a typical paprika batch?**
A: Batch sizes vary from a few hundred kilograms to several metric tons, depending on the production scale and processing equipment.

**Q: Can I combine multiple batches in one shipment?**
A: Yes, but each batch should have its own COA. A consolidated COA covering multiple batches may be provided for mixed shipments.
