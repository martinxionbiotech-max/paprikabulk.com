# ASTA Color Value

## Definition

ASTA (American Spice Trade Association) color value is the standardized measurement of the red coloring capacity of paprika and other red spice products, expressed as a numerical value (e.g., ASTA 120, ASTA 180, ASTA 200).

## Overview

ASTA color value is the single most important quality parameter for paprika in international trade. It quantifies the concentration of carotenoid pigments (primarily capsanthin, capsorubin, beta-carotene) that give paprika its characteristic red color. Higher ASTA values indicate more intense red color and greater coloring power.

## Technical Explanation

**Measurement Method:**
1. A representative sample is extracted with acetone
2. The extract is measured by spectrophotometer at 460 nm
3. Absorbance is converted to ASTA units using a standardized formula
4. Results are expressed as ASTA color value (also called "ASTA units")

**ASTA Value Ranges for Paprika:**

| Grade | ASTA Range | Typical Use |
|-------|-----------|-------------|
| Standard | 80–120 | General food coloring, seasoning blends |
| Superior | 120–160 | Premium seasoning, processed meats |
| Premium | 160–200 | High-color applications, sausages |
| Special | 200+ | Maximum color, oleoresin extraction |

**Interpretation:**
- ASTA 100: Minimum acceptable for most commercial applications
- ASTA 150–180: Premium export grade
- ASTA 200+: Specialty high-color grade
- Each 10-point increase = approximately 10–15% more coloring power

## Importance in Paprika Documentation

ASTA color value is the primary specification parameter on every COA and spec sheet. It directly affects pricing — higher ASTA commands premium pricing. Buyers must verify ASTA values match their application requirements.

## Frequently Asked Questions

**Q: What is the minimum ASTA value for acceptable quality?**
A: For most commercial applications, ASTA 80 is the minimum. Premium-grade products typically require ASTA 160+.

**Q: Does ASTA value decrease over time?**
A: Yes. Carotenoid pigments degrade with exposure to light, heat, and oxygen. Proper storage (cool, dark, sealed) minimizes degradation. Expect 5–10% loss per year under optimal conditions.
