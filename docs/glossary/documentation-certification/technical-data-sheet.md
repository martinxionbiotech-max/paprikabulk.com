# Technical Data Sheet (TDS)

## Definition

A Technical Data Sheet (TDS) is a document that provides comprehensive product information for a paprika product, including specifications, physical/chemical properties, applications, and handling instructions.

## Overview

The TDS is the primary reference document for product specifications. It describes the standard characteristics of a product grade, while the COA provides batch-specific test results against those standards.

## Technical Explanation

**Typical TDS Contents:**

| Section | Information |
|---|---|
| Product Identification | Name, grade, SKU, category |
| Physical Properties | ASTA color value, particle size, moisture, bulk density |
| Chemical Properties | Pungency (SHU), total ash, acid-insoluble ash |
| Microbiological | Typical limits for pathogens and indicator organisms |
| Nutritional | Proximate analysis (if required) |
| Packaging | Standard pack sizes, packaging materials |
| Storage | Temperature, humidity, shelf life |
| Applications | Recommended uses, usage levels |
| Regulatory | Certifications, allergen status, GMO status |

**TDS vs. COA:**
- **TDS:** General specifications for the product grade
- **COA:** Actual test results for a specific batch

## Importance in Paprika Documentation

The TDS is the first document to consult when evaluating a product's suitability. It should be reviewed alongside the COA for complete product understanding.

## Frequently Asked Questions

**Q: Is the TDS the same for every batch of the same grade?**
A: The specifications are consistent, but actual TDS content (like test results) may vary by version. The COA is batch-specific.

**Q: Can a TDS be used for regulatory submissions?**
A: Yes, but the batch-specific COA is also required to demonstrate that the actual product meets the TDS specifications.
