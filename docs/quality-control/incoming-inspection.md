# Incoming Inspection Checklist

Use this checklist when receiving paprika shipments.

## Pre-Inspection

| Check | Pass/Fail | Notes |
|-------|-----------|-------|
| Documentation matches shipment (product name, grade, quantity) | | |
| Batch/lot number on COA matches product labels | | |
| COA test results meet specifications | | |
| Certificate of Origin matches | | |

## Physical Inspection

| Check | Pass/Fail | Notes |
|-------|-----------|-------|
| Packaging condition (no tears, holes, moisture damage) | | |
| Container condition (no odors, pests, moisture) | | |
| Product appearance (color, uniformity) | | |
| Absence of foreign material | | |
| Odor (characteristic, no off-odors) | | |

## Sampling

| Check | Completed | Notes |
|-------|-----------|-------|
| Representative samples collected per sampling plan | | |
| Samples labeled with batch number and date | | |
