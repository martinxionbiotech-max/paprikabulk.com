# Spectrophotometer — Calibration and Use for ASTA Measurement

## Purpose

A UV-Vis spectrophotometer is the core instrument for ASTA color value measurement (ASTA Method 20.1 / ISO 7541). The instrument measures absorbance of acetone-extracted carotenoids at 460 nm.

## Calibration Requirements

| Parameter | Requirement | Standard |
|:---------:|:-----------:|:--------:|
| Wavelength accuracy | ± 1 nm at 460 nm | Holmium oxide or didymium filter |
| Photometric accuracy | ± 0.005 A at 1.0 A | Neutral density glass filter |
| Stray light | < 0.05% at 340 nm | Cut-off filter |
| Calibration frequency | Monthly | Per ISO 7541 |
| Wavelength range | 200–800 nm minimum | For carotenoid work |
